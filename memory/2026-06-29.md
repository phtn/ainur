# 2026-06-29

- Added MeloTTS as a first-class TTS provider in Cale. It targets the service described in `MELO_TTS.md` with `/voices`, `/languages`, and `/synthesize`.
- New config keys: `meloTtsEndpoint`, `meloTtsVoiceId`, `meloTtsLanguage`, and `meloTtsSpeed`. Environment overrides use `CALE_MELO_TTS_*` or `MELO_TTS_*`.
- CLI/REPL controls now include `tts use melo`, `tts melo`, `tts voice`, `tts language`, and `tts speed` for MeloTTS.
- Verified against the live local MeloTTS service on port 8000 using voice `theron-edf501e0cc`; synthesis returned a hosted WAV URL and downloaded a 131 KB WAV through the TypeScript client.
- Updated MeloTTS voice selection so users can select by the first id segment before `-`, e.g. `cale tts voice theron`; duplicate aliases prefer a single `embedding_ready: true` voice when available.
